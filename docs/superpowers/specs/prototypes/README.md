# 示意稿

纯静态页面，数据全是编的，用浏览器直接打开：

```bash
open docs/superpowers/specs/prototypes/2026-10-02-workstation-v7.html
```

只放在本地，不发布到任何云端。定稿的文字版见 [个人工作站 —— 产品设计](../2026-10-02-workstation-product-design.md)。

| 版本 | 探索了什么 | 结论 |
| --- | --- | --- |
| [工作台 v0](2026-10-01-workbench-v0.html) | 页签式：会话、应用中心、我的空间、连接、我的 skill | 否：管理后台的样子，不是一台电脑 |
| [工作站 v1](2026-10-01-workstation-v1.html) | 整屏桌面、底部对话是入口、窗口由对话打开 | 方向对；但面向的还是"应用"，不面向业务 |
| [工作站 v2](2026-10-01-workstation-v2.html) | 同事列表（财务、行政、人事各是一个 agent）、我的事项、把文件丢给同事、按人改称呼与性别 | 否：员工只有一个助理；财务是助理去办的事 |
| [工作站 v3](2026-10-01-workstation-v3.html) | 一人一个助理；它调接口或去对接别的部门的岗位助理；待办合并三种 | 对；但别的部门的助理不该显示 |
| [工作站 v4](2026-10-02-workstation-v4.html) | 部门助理透明，只显示「某部门 · 进展」 | 对 |
| [工作站 v5](2026-10-02-workstation-v5.html) | 加日程：飞书日历 + 待办 + 定时 + 截止一条时间线 | 对；但不该常驻 |
| [工作站 v6](2026-10-02-workstation-v6.html) | 日程、待办、事项改为按需打开的窗口，桌面只常驻对话 | 对 |
| [工作站 v7](2026-10-02-workstation-v7.html) | 输入框带附件：从空间选、上传、拖拽、粘贴 | 对，**以此为准** |

每一版都是在前一版上改的，旧版留着是为了看清否定过什么，别再提。
