# R3 到人优先补充设计

2026-10-23 用户确认当前没有业务部门，交办和审批优先直接指定员工。本补充取代原计划把真实部门和四名员工作为当前试点前置条件的部分。

- 发起人明确选择已启用员工承办；不创建占位部门，不从企微可见范围或管理员身份推断业务职责。
- 直接接收人仅取得本次交接资料包及提交成果所需权限，不自动成为完整事项编辑者或获得全局业务角色。
- 审批策略支持明确指定员工的顺序步骤，保存稳定员工标识、身份代际和策略版本。申请人与当前审批人不得相同，审批时再次核对身份和权限。
- 改派由事项负责人明确指定新承办人并记录原因和历史；新承办人重新接收，停用员工不触发自动改派。
- 部门队列、岗位职责和组织来源保持可选能力。直接到人和部门两条路径共用版本、幂等、撤权、固定材料和审计约束。
- 两名真实员工可以验证发起、承办、审批、交付和发起人签收；组织审批与签收分别留记录。当前试点不宣称已通过真实多部门、四人竞争验收。

实施顺序保持 B → C → D → E。B 提供可选组织基础，C 提供员工或部门授权，D 同时支持到人和部门分支，E 按实际两人条件验收并标明未执行场景。
