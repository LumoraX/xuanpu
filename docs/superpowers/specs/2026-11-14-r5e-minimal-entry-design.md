# R5-E：极简入口设计

日期：2026-11-14。状态：待实施。上级：[R5 设计](2026-11-14-r5-butler-artisan-design.md)。概览接口依赖 R5-B；对话内卡片依赖 R5-C。

## 1 目标

员工页只有四样：概览、对话、一个输入框、提示。其余功能都在后端，由对话触达。

## 2 页面

```
┌ 概览 ─────────────────────────────────────────────┐
│ 今天 · 等我处理 · 进行中 · 未读通知                  │
├ 对话 ─────────────────────────────────────────────┤
│ 消息、确认卡、列表卡、进展卡（可展开执行树与瀑布）     │
├ 提示 ─────────────────────────────────────────────┤
│ 试试这样说 …                                        │
├ 输入 ─────────────────────────────────────────────┤
│ [ 附件 ]  告诉我你想办什么                [发送/停止] │
└───────────────────────────────── 更多 · 通知 · 退出 ┘
```

- 去掉常驻侧栏、8 个模块按钮、业务对话记录列表、浮层面板。
- 「更多」链接进入现有功能页（AGENTS.md 要求的手动兜底），默认不加载其脚本。
- 管理员入口 `?admin=1` 不变。

## 3 概览

`GET /v1/dashboard`（拟），一次返回四块，每块含数量与最多 5 条摘要：

| 块 | 来源 | 点击 |
| --- | --- | --- |
| 今天 | 今日提醒、日程、到期待办 | 在对话里展开列表卡 |
| 等我处理 | 待确认写入、审批、匠人提问、高分歧裁决 | 定位到对应卡片 |
| 进行中 | 活动 trace：标题、阶段、谁在做、是否在等我 | 展开执行树 |
| 未读通知 | 通知中心 | 打开通知 |

数量在授权过滤之后计算，不从当前页推算；某一块读取失败单独显示失败，不拖垮其余。接口不依赖模型。

## 4 对话内卡片

- 现在返回「已打开你的文件」并开窗的路由，改为返回列表数据，渲染成对话里的卡片，带与原模块相同的操作（同一接口、同一权限、同一幂等键）。
- 必须本人原生选择或确认的动作（共享资料选择、交接接受与审批）变成卡片上的明确按钮，仍由本人点击，不由模型代做。
- 进展卡：一条 trace 一张，实时更新；展开看执行树，再点看瀑布。记录不完整时明确标注。

## 5 提示

- 确定性生成，不调用模型：依据本人可用匠人、当天是否有待处理项、是否首次使用。最多 3 条。
- 系统状态提示（模型不可用、预算将尽、连接授权过期）用同一位置，说明能做什么。

## 6 兼容与清理

- 旧页面在一个版本内以 `?classic=1` 可达，之后删除不再使用的脚本；功能页自己的脚本保留。
- 切换身份、注销清空概览、卡片与草稿；旧的异步结果不得回填新身份（沿用现有代际校验）。
- 375px 无横向溢出；键盘可达；状态变化有读屏播报。

## 7 验收

真实浏览器：首屏只见四样；提醒、待办、文件、交接、共享各在对话内完成一次查看与一次确认；模型屏蔽时概览、通知、「更多」可用；两员工互不可见；刷新后进展卡恢复；默认页加载的脚本数与体积记录在验收文档里。
