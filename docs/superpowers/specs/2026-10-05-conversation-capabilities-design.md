# 对话中的系统能力

用户已明确：提醒属于隐藏的系统能力，不能因说了“提醒”就出现左侧手工新建模块；沿用自主实施、本地验收和主线部署授权。

采用按需对话卡片。移除侧栏提醒模块、手动新建按钮和常驻创建提醒快捷项；登录、后台刷新、创建成功、到点通知都不得自动展开提醒管理。自然语言仍生成确认卡，确认成功显示结果。用户明确查看/修改/取消提醒时，才在对话区出现本人清单及相关修改/取消动作，清单可收起。新对话、切换会话、退出清除临时能力界面。

通用“通知”入口放在顶栏，与能力管理分开；显示本次读取范围内未读提示，无通知时保持普通入口。点击才展开通知面板，到期更新提示但不夺取焦点或强行弹出列表。标读和离线补读保留，登出清空并取消后台流。后台调度、持久化和权限不变。

只折叠原左侧模块仍会暴露管理工具且误导入口；彻底删除管理能力会失去查看与纠错途径。因此选按需展示。保留明确的时间确认和修改表单，因为它们在用户正在处理具体任务时出现；本次不新增模型直接改写提醒能力，不把已有列表路由描述成已理解并执行某条修改。

验收：登录无提醒面板/手动新建；自然语言创建不展开清单；到期仅更新通知提示；点击可读；说“查看我的提醒”出现对话内清单，可修改取消并收起；新对话、切换用户和过期异步回包不能重新展开；375px无横向溢出。
