# 外部计划、专用批准与未知核对

外部计划固定目标版本、金额、账户/账套、期间、策略与通道配置版本。原业务批准不等于专用批准，原计划不能通过复制决定或延期复活。
202/accepted只证明持久受理。付款成功必须外部transaction_id及证据；入账或冲回成功必须匹配ledger_id、accounting_period、voucher_id及证据。状态字符串或模型回复不是回执。
outcome_unknown保持金额占用，仅按原external_request_id查单；not_found不是安全重发证明。人工核对和取消交真实员工入口，模型不重新提交。
simulation回执只能留在独立隔离测试记录，真实供应商尚未接入；税务和正式归档不属于当前F2交付。
