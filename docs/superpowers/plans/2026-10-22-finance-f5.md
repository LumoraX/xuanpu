> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 完成预付、员工垫付、委托收款及预付核销/退回的专用内部闭环，保持独立DB/原件、7个Skill、API和真实HITL。

**Architecture:** 基于现有finance_expense_claim加入funding_case类型、严格scenario与不可变授权/凭据责任及核销台账；复用F1实际顺序审批与F2固定请求/查询引擎。支持材料复用F0持久收件而不解析发票，F3/F4扩展真实目标与证据。实际供应商仍未选，正式能力不默认启用。

**Tech Stack:** Python3.12、Pydantic2、FastAPI、asyncpg/PostgreSQL16、AES-GCM、原生JS、Ed25519、现有HTTP适配器及pg_dump/pg_restore。

```python
class FundingDraft(StrictModel):
    legal_entity_id: Identifier
    scenario: Literal['prepayment','employee_advance','entrusted_collection','prepayment_clearance','prepayment_return']
    reason: Reason
    amount: Money
    due_date: str
    supplier_ref: BusinessRef
    business_refs: list[BusinessRef]
    evidence_ids: list[Identifier]
    source_case_id: Identifier | None = None
    authority: FundingAuthoritySpec | None = None

class FundingUpdate(StrictModel):
    expected_version: Version
    draft: FundingDraft

async def create_funding_case(self, who, body: FundingDraft, key): ...
async def update_funding_case(self, who, id, body: FundingUpdate, key): ...

async def get_funding_options(self, who, entity): ...
async def revoke_funding_authority(self, who, id, expected_version, reason, key): ...
```
