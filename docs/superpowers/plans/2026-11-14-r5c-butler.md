# R5-C 管家实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans，依赖 A、B。

**Goal:** 管家自己办完，或派给一个匠人并在验收后交付。

**Architecture:** 见 [R5-C 设计](../specs/2026-11-14-r5c-butler-design.md)。管家是平台内置技能加平台工具；派工落到 R2 任务或既有会话；唤醒由持久记录驱动。

**Tech Stack:** taifeng 稳定层（引擎池、`todo_write`、`request_user_input`）、既有 `assistant_*` 提案模型、R2 `work_tasks`、PG 协调事务。
