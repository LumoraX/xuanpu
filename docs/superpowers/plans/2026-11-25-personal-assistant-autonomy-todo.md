# 私人办公助理自主化与企业信息自动整理 TODO 规划

> 记录时间：2026-11-25
> 目标定位：打造**完全自主的私人办公助理（私域可替代干活、一键可撤回）+ 企业办公助手（匠人编排与闸门审批）+ 信息自动整理工具**。

---

## 一、已落地能力（阶段一：私域自主办理闭环）

- [x] **个人知识图谱底座**（`server/domains/people/`，迁移 `0033` + `0034`）：原始记录（随手记/会议纪要/名片/通话）→ 公司 + 人物 + 事项 + 待办/日程/提醒 + 1–3 跳跨实体关系图谱。
- [x] **管家全域个人只读感知**（`server/engine/butler/personal_actions.py`）：`read_personal` 覆盖 `today`（今日全景）、`todos`、`events`、`reminders`、`files`、`file_content`（UTF-8 文本）、`knowledge`（知识库与工作记忆）、`followups` 与全部图谱查询；个人偏好（称呼、风格、`auto_execute_personal`）及个人技能注入每轮上下文。
- [x] **私人事务自主办理与一键撤回**（`act_personal` + `POST /v1/assistant/actions/{request_id}/{action_id}/undo`）：默认开启本人私域直接办理（`capture_bundle`、待办新建/修改/完成/重开、日程新建/改期、提醒新建/取消、事项新建/更新、`save_note_file` 存为 Markdown 文档），支持同一轮多动作连续执行与一键撤回；关闭开关自动退回 `propose` 草稿确认；企业对外/审批/共享/交接仍严格走确认与审批闸门。
- [x] **小院极简入口联动**：顶栏「自主办理：开/关」切换、输入框「附件」上传（`input_files`）、对话内「助理已办好」回执卡与撤回态恢复、小院管家气泡实时跟随流式步骤。

## 二、待办规划 TODO（文档 · 图片 · 主动感知 · 团队整理）

### TODO 1：多格式文档自动解析与归档（文档）
> 现状：`file_content` 与知识库当前仅支持 UTF-8 文本（TXT / MD / CSV / JSON），二进制文档会被拒绝。

- [ ] **Office / PDF 文本与表格提取服务**（新增受控解析层，限制单文件大小、页数、解析超时与解压炸弹防护）：
  - [ ] `PDF`：提取分页正文与基础表格（区分扫描件与可选中文本，扫描件转入 OCR 管道）。
  - [ ] `DOCX`：提取标题层级、段落、表格与批注（合同、方案、会议纪要）。
  - [ ] `XLSX`：按工作表提取表头与行数据摘要（报价单、客户清单、项目进度表，支持转成结构化片段）。
  - [ ] `PPTX`：按页提取标题、要点与演讲者备注。
- [ ] **长文档分段自动整理管线**：
  - [ ] 超过单轮上下文窗口（如 >12,000 字）的文档支持分页/分块索引，提供 `read_personal(kind="file_content", page/offset)` 按段翻阅，或交给专门的文档整理匠人处理。
  - [ ] 解析结果一键沉淀进个人知识库（`knowledge`）并自动关联对应 `matter_id`，实现「丢进一份 PDF/Excel → 自动提取人物/公司/待办/关键结论 + 长期可检索」。
- [ ] **自动生成可交付格式**：除 `save_note_file` 导出 Markdown 外，按需支持导出整理好的 CSV / DOCX 摘要文档。

### TODO 2：图片与多模态感知理解（图片）
> 现状：前端仅支持头像与普通文件上传，管家模型尚不能直接“看图”或识别图片里的名片、截图与白板。

- [ ] **输入框图片直传与粘贴（Paste / Drag & Drop）**：
  - [ ] 小院 `#composer` 支持 `Cmd/Ctrl+V` 直接粘贴截图、拖拽多张图片、缩略图预览与魔数校验（JPEG / PNG / WebP，拒绝 SVG）。
- [ ] **多模态视觉输入与图片内容提取**：
  - [ ] 核对内核 `taifeng` 的多模态消息/工具返回能力，把本轮 `input_files` 中的图片安全送入视觉模型，或新增受控图片解析工具 `read_personal(kind="image_extract")`（OCR + 视觉结构化描述）。
- [ ] **高频办公图片自动整理场景**：
  - [ ] **名片拍照/微信名片截图** → 自动识别姓名、公司全称、职位、电话、微信、邮箱、地址，查重后直接用 `act_personal(capture_bundle)` 建档/补全并关联原图附件。
  - [ ] **微信/飞书聊天记录长截图** → 自动提炼各方承诺、待办行动项、截止时间与相关人关系网，直接落库待办与提醒。
  - [ ] **会议白板 / PPT 拍照** → 自动整理为结构化 Markdown 会议纪要（`save_note_file`）+ 拆解行动项。
  - [ ] **发票 / 合同关键页 / 行程单截图** → 提取时间/地点/航班酒店/关键条款，自动建日程与出发提醒，或直接附带原图派给财务/出行匠人。

### TODO 3：主动感知与定时自动整理（感知）
> 现状：`proactive`（承诺跟进扫描）、`reminders`（定时提醒）与 `task_triggers`（定时任务）已在后台存在，但尚未与管家的全域个人整理能力形成主动闭环。

- [ ] **每日晨报 & 今日优先级自动排程（定时主动推送）**：
  - [ ] 每天早上按本人时区（遵守 `quiet_hours` 免打扰窗口）自动聚合 `today`（日程、逾期待办、今日待办、提醒、卡点跟进），在主对话生成简洁的「今日简报与建议处理顺序」并推站内/飞书通知。
- [ ] **会前自动准备简报（日程感知）**：
  - [ ] 日程开始前 N 分钟（如 30 分钟），自动识别参会人物/关联项目，调 `entity_graph` + `records_search` 拉出上次沟通纪要、未决问题（`open_questions`）与未完待办，主动推送「会前 1 分钟速览」。
- [ ] **周报 / 项目复盘自动汇总存盘（周期整理）**：
  - [ ] 按周/按项目自动汇总本周新增原始记录、已完成与逾期未完待办、关键决策与新认识的人脉/公司，自动调用 `save_note_file` 生成本周复盘 Markdown 文档并通知员工查阅。
- [ ] **承诺、待办与人脉维护的主动感知推进**：
  - [ ] `proactive` 后台感知到「某待办连续逾期 / 某承诺到期未闭环 / 某重要联系人临近生日（`birth` 字段）」时，不仅生成被动跟进条目，还提供一键快捷动作（延后一天、设为提醒、标为完成、生成问候草稿）。
  - [ ] 支持管家通过 `act_personal` 直接处理主动跟进状态（如员工口述「那个跟进不用管了 / 延后到下周一」）与创建定时整理任务（如「每周五下午 5 点自动帮我汇总壁仞项目进展」）。
- [ ] **外部只读信息源感知接入（可选连接器）**：
  - [ ] 基于已有企业微信/飞书只读连接，按本人显式授权范围定时拉取未读邮件/消息/日程变更，自动归类待办与人脉更新（严格只读、不越权代发）。

### TODO 4：企业级信息自动整理与可控共享（团队扩展）
- [ ] **个人整理 → 团队共享的可控发布投影**：把个人整理好的会议纪要、项目全景、客户名片通过显式「发布到共享事项 / 企业知识库」动作投影给指定成员，默认剔除个人私密备注（`note` / 私人评价），确保私域与公域边界清晰。
- [ ] **混合检索升级（`pgvector` 语义召回）**：对 `xp_personal_note.content`、`xp_personal_person.summary` 与解析后的文档分块建向量索引，与现有精确/图谱多跳检索融合，解决“记得聊过某件事但忘了准确关键词”的问题。

## 三、推荐实施优先级

1. **优先 P1（图片 + 文档解析）**：先把 **PDF/DOCX/XLSX 文本提取** 与 **聊天输入框图片粘贴/名片截图识别** 打通，让员工日常 90% 的非纯文本信息（截图、名片、合同、纪要文档）都能直接丢进小院自动整理。
2. **次优 P2（主动感知闭环）**：把 **每日晨报、会前 30 分钟图谱速览、周报自动存盘、口述处理 `proactive` 跟进** 接上后台调度，让私人助理从“叫它才干活”升级成“主动替你盯着”。
3. **后续 P3（语义检索 + 团队发布投影）**：接入 `pgvector` 与可控共享投影，支撑企业级公共信息自动整理。
