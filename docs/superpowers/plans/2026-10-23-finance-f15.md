# F15 真实模型发票报销验收 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax for tracking. 用户已经授权本地实施与提交，不再询问执行方式；只在全部门禁完成后由主agent提交。

**Goal:** 在隔离财务环境中，用真实模型完成已发布Skill的完整员工旅程，修复实测问题，交付缺失正式资料清单和可核查证据。

**Architecture:** 复用生产GatewayModelClientFactory、Platform、公开route/session与人工HTTP接口、独立PostgreSQL财务服务；不使用旧ModelBlocker装配。记录原始模型请求/响应与单独业务判定，合成身份只扮演测试员工，不冒称真实人员验收。

**Tech Stack:** Python3.12、taifeng稳定导出、httpx/uvicorn、asyncpg、pytest、Ruff、strict mypy。
