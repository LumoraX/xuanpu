# R4 业务能力可复制交付实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans，逐任务实施、保留检查点。本轮交付计划，不自动开始实现。

**Goal:** 把一个有明确输入、权限、输出和验收的办公能力，安全地复制交付给不同员工和企业，并能评测、升级、撤销及回退。

**Architecture:** 在现有不可变业务包、R2任务、R3身份/协作/来源保护上增加交付治理，不另建执行内核。员工默认对话使用，保留独立功能入口；按人分配为默认，部门/岗位可选。

**Tech Stack:** Python 3.12、Pydantic、FastAPI、asyncpg/PostgreSQL、既有ObjectStore、taifeng稳定接口、原生JS、pytest；依赖以开工时uv.lock为准，不因本计划升级内核。

## 3 文件与接口约定

下文分计划中，`S/`表示`packages/xuanpu-server/src/xuanpu_server/`，`T/`表示`packages/xuanpu-server/tests/`，`C/`表示`packages/xuanpu-console/src/xuanpu_console/static/`，`Q/`表示`packages/xuanpu-console/tests/`，`SDK/`表示`packages/xuanpu-sdk-py/src/xuanpu_sdk/`，`CLI/`表示`packages/xuanpu-cli/src/xuanpu_cli/`。花括号只表示列出的具体文件；新增Python目录同时创建中文docstring的`__init__.py`。

所有新命令接口：认证提供tenant/actor；mutations带`request_id`，修改现有对象带`expected_version`；同键同body回原回执，不同body409；无数据权限404、缺少必需身份403；Cookie写接口保留CSRF。取消与未知结果沿用R2口径。对象有租户复合外键，不因可猜ID跨企业读写。

列表默认50、上限100、稳定复合游标；总数独立于当前页且在授权过滤之后计算。API输入不接收Secret、任意模型客户端、宿主路径、代办员工或shell命令。员工错误只解释可采取动作，不暴露其他人的存在与正文。

新增配置对象`capability_delivery`、`knowledge`、`business_outcomes`默认`enabled=false, tenants=[]`；显式白名单与enabled同时匹配才启用新受理，空名单保持关闭，不继承旧R2空名单全量语义。关开关不移除已纳管包执行检查或来源撤权检查。

## 5 公共测试夹具与验收样本

由A0创建`T/r4_contract/conftest.py`、`seed.py`和`client_helpers.py`：

- `r4_http: dict[str,httpx.AsyncClient]`：alice/bob/admin/outsider/machine；前两者为同租户真实测试Cookie+CSRF、admin为租户管理员、outsider另一租户、machine无员工。全为合成身份，不伪造生产本人登录。
- `r4_ids: dict[str,Any]`：基础seed明确创建两租户、员工、真实测试岗位/任职、测试包归档及digest；后续任务扩展capability/installation/assignment/release/source/batch字段。HTTP测试不用管理密钥假扮普通员工。
- `r4_clock`：注入确定时钟的`now()/advance(seconds)`；并发/事务与进程故障仍使用真实PG，不以改dict伪造重启。
- `r4_model`：记录实际请求/可阻塞的替身，真实模型验收另配私有网关；不会把替身结果计入真实模型列。
- `r4_pack(version, permissions)`：返回可由当前PackageRegistry校验的内存ZIP；name固定`office-review`，入口`review`，结构为`xuanpu.yaml`、`skills/review/SKILL.md`，digest由服务端计算。
- `r4_seed_delivery(alice, enabled=True)`：测试专用seed，返回精确`capability_id/revision/installation_id/assignment_id/release_id`；生产API不提供跳过评测的seed入口。
- `r4_pg`：独立schema/对象目录，同一契约运行memory/PG；SIGKILL测试用独立解释器与命名空间，不连接生产，也不和财务测试共享库、端口或清理脚本。

最小安全矩阵：目录枚举→显式version绕过→续聊→工具批准→定时发生实例→运行时撤权→模型中途撤权→迁移后关闭新受理→冷恢复→版本回退→来源删除→报告导出。每项都记录当前层真实证据；`skip`不算pass。
