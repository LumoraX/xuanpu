## 3. 接下来要做的

### 3.1 Task 7：每日对账

计划里的任务原文仍然有效，下面是写计划之后才定下、可直接复用的东西：

- **挂进现有周期任务**：`identity/maintenance.py` 的 `IdentityMaintenance`（`Platform.start()` 经 `IdentityService.start()` 启动、`close()` 时取消并等待；每 5 分钟清一次过期登录记录；间隔可注入）。对账在同一个循环里做，不另起循环。
- **存储已有**：`list_identity_configs("feishu")`（不带租户）、`list_external_identities(tenant, provider, *, user_id, user_status, after_subject, limit)`、`claim_reconcile(tenant, *, owner, now, interval, lease_seconds)`（手工触发传 `interval=0`）、`finish_reconcile(tenant, *, owner, now)`、`get_reconcile_state`、`mark_user_unverified(*, at)`（只在为空时设，返回是否设了）、`clear_user_unverified`。
- **飞书客户端已有**：应用身份令牌（文档核过：最长 2 小时，剩余不足 30 分钟才发新的）与批量查员工（`user_ids` 为重复查询参数、`user_id_type=union_id`、每批 ≤ 50）。
- **每租户出站并发上限**：复用 `identity/limits.py` 的 `TenantCallLimit`。
- **停用**：`IdentityService.disable_user(..., keep_an_admin=False)`（**已定：对账与离职事件都不保最后一名管理员**，兜底靠平台管理员重新指定）；系统调用者 `tenancy.system_principal(tenant, "reconcile")`；原因映射复用 `identity.events.reason_from_status`（离职 > 退出 > 暂停，都为假按 `feishu_resigned`）。
- **要在实现时决定并写明的**：飞书报错中止后的重试语义（设计说「下个周期再试」，但周期是一天——建议失败时只释放租约、不记完成时间，或较短退避；必要时给存储加「释放租约但不记完成」的方法并补契约测试）；只对 `active` 且已绑定 `feishu_tenant_key` 的租户对账。
- 指标建议：`xuanpu_reconcile_runs_total{result}`、`xuanpu_reconcile_users_total{outcome}`，不带租户标签。
- 手工触发 `POST /v1/identity/feishu/reconcile`：租约被占时 409。

### 3.2 Task 8：控制台

计划原文之外，审查中积累的要求：

- 加 `X-Frame-Options: DENY` 或 CSP `frame-ancestors 'none'`。
- 飞书返回的 `avatar_url` 与 `display_name` 显示时要转义，头像地址只收 `https`。
- cookie 模式下写请求带 `X-Requested-By: xuanpu`；登录 cookie 名随 `cookie_secure` 而不同（控制台不读 cookie，不受影响）。

## 4. 工作方式（接手时照做）

- 每个任务派一个子代理实现，做完派一个独立的审查子代理（先对照需求、再看代码质量与安全），审查查出的问题退回实现者修，修完再进下一个任务。审查多次查出真问题，这道工序值得保留。
- 给子代理的提示词里写明：**可能超过 3 分钟的命令一律后台跑、短命令轮询**，不要在前台长时间等待——十分钟没有输出会被判为卡死（本轮卡死过五六次，都是这个原因）。起本地服务也要后台起、用完杀掉。
- 门禁：`uv run pytest -q`、`uv run ruff check --select F,S108,I,TC packages`、`uv run mypy packages/*/src`、`uv lock --check`。shell 里 `VIRTUAL_ENV` 指向别的仓，`uv run` 会忽略它并给出警告，属正常。
- 文档覆盖测试（`packages/xuanpu-cli/tests/test_examples_and_docs.py`）要求新路由、错误码、配置键、审计类型、指标都写进文档；每个任务顺手补自己新增的。
- 大文件不要再变大：`runtime/sessions.py`（593）、`controlplane/postgres.py`（506）、`api/app.py`（372，但约定新路由放 `api/` 下的新模块）、`runtime/connectors.py`（525）。测试：`tests/conftest.py` 与 `tests/identity/test_identity_auth.py` 不再加东西，身份相关测试放 `tests/identity/`（有自己的 `conftest.py` 与 `IdentityWorld`）。
- 中文 docstring、注释、文档、commit message；commit 结尾带 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。内容只写本地，不发布到云端。
