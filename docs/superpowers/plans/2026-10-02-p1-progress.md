## 4. 实现中需要记住的边界

- 对账复用同一维护循环；每 50 人、120 秒租约、每批/员工/完成前续期、每步 30 秒。失败不推进完成时间，下维护周期重试；缺状态不误停用，查不到只标记。
- 完成时间落库后再写成功审计。此后审计故障可能让接口报错，但不撤销完成或写相反终态；日志与成功指标辅助排查。
- Platform.close 最先停身份维护，之后才收尾停用、会话和运行时。
- 无签名加密 URL 验证依据官方 SDK 与 OpenClaw 报文观察，非飞书文档原文；真实应用仍待核实。
- 0004 普通审计索引会阻塞写入；枚举新增先升级读取者再开放写入。用户 ID 为 usr_ 加 24 位十六进制。
- 管理员仍可读全部会话正文，ADR 0011 规则 7 要在 P6 前收紧；P0 外部主存仅 Chat 限制保留。
- SDK 代调用是固定客户端身份，不是提权；普通成员只能访问本人会话，旧响应缺 user_id 解析为 None。
