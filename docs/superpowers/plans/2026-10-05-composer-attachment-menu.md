# 输入框与附件菜单调整

依据用户提供的输入框/添加菜单截图，以及本会话持续有效的自主实现和本地升级授权。

**目标：** 输入区在上、工具栏在下；“＋”位于左下角，附件菜单可切换关闭，不破坏业务确认。

**设计：** 保留原生HTML/CSS及现有静态脚本，不引入组件库。圆角输入容器包住附件标签、正文、左下工具和右下发送/停止。独立附件菜单锚定加号上方，提供本机上传、个人文件选择两条既有路径。普通用户无需额外配置。

相比侧栏或整行展开方案，锚定菜单保留当前输入空间，也避免挤动对话；菜单与`workspace-draft`分离，确认卡中的编辑不会丢失。
