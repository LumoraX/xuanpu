# 玄圃macOS客户端打包

**目标：** 为当前Apple Silicon Mac生成可双击打开的玄圃.app和拖入Applications安装的DMG，连接现有本机玄圃服务。

**已确认方案：** 用户接受上一轮的Tauri桌面客户端方案并要求实际打包；本轮复用现有隔离工作树，按交互设计、实现计划和独立审查流程执行，不重复询问常规构建决定。客户端与企业后台分离；本机版默认127.0.0.1:8420，数据库、业务调度和密钥继续由已部署后台管理。

**架构：** packages/xuanpu-desktop提供Tauri原生壳、离线连接页、打包配置与文档。业务页面直接使用服务同源URL以保留HttpOnly会话、PKCE登录、SSE、文件接口。客户端独立保存登录状态，不导入其他浏览器cookie。没有通用文件系统或shell前端权限；仅本地连接页能请求连接到管理员预置服务。服务URL只允许HTTPS或loopback HTTP，禁止含用户名/密码。非业务外部HTTPS链接交给系统浏览器，授权域名在客户端中正常重定向回玄圃。原生下载写入用户Downloads的唯一文件名，不覆盖同名旧文件。

**边界：** 交付的是连接已部署服务的前端客户端；不打包Postgres/Docker/模型密钥，不承诺后台离线仍可执行业务。Mac本机构建使用本地签名；跨机器正式分发仍需Developer ID和公证。
