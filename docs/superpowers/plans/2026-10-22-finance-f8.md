# 财务 F8 实际使用与端到端验收实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 员工能通过附件点选与持久收件记录继续办理内部报销，并用实际浏览器完成真人审批闭环。

**Architecture:** 沿用独立finance PG和加密原件、原导入幂等和真人计划；新增两项当前员工只读收件查询，界面恢复线索不取代服务端事实。

**Tech Stack:** Python3.12/FastAPI/Pydantic/asyncpg、PostgreSQL/AES-GCM、OpenAPI/7 Skills、原生JS、隔离回环HTTP及实际浏览器。
