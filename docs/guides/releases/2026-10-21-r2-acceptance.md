## C0/C1 员工能力

本人任务视图集中过滤宿主路径、owner、epoch、原始工具参数和凭据；展示阶段、执行次数、预算阻塞、来源安排、恢复方式和安全批准摘要。通知在员工事务中按语义转移去重，轮询和短重试不产生新通知。SDK/CLI 使用同一服务与本人身份。

对话只能生成执行安排草稿，原生确认才创建安排。直接入口支持创建、查看、修改、暂停、恢复、取消；固定输入版本、时间、时区、错过行为、次数、预算和失效条件可见。身份切换丢弃旧响应，同一请求重试沿用原 request_id，旧版本冲突刷新。未知结果没有绕过效应屏障的重试按钮；开关关闭后仍支持必要的直接读取和取消。

原生 HTTP 验收还确认：机器凭据无员工身份 403，另一成员和管理员以自己的员工身份读取他人任务 404，缺少 CSRF 403，SDK/CLI 本人列表可读。查询可用不能据此宣称真实企业登录完成。

## 实际模型、调度与业务语义

先隔离预发布，后生产合成租户。生产先仅开放 durable，再开放 triggers/activity；最终补丁镜像重新执行完整 6 个 HTTP 场景，全部通过：CSV、XLSX、会议行动项、无附件只读工单，以及两个实际到时调度周期。另运行一次真实主动扫描，耗时 39.0068 秒；扫描产生的合成过期待办随后回收。

- 表格独立检查 CSV、XLSX 的实际 XML、金额与下载 SHA，A=12.50、B=3.00、合计=15.50，四份成果齐全。
- 会议独立检查日期、时区、提醒时刻、准确原文引用与字符区间；不明确的日期保留未知，其他同事任务不自动分派。能力包增加精确引用和带时区时间计算脚本，拒绝 DST 歧义/不存在时间。
- 工单读取具有真实 `api__tickets__getTicket` 回执，并实际执行当前技能登记的 SLA 脚本，T-1001 得到 24 小时；不能只凭模型陈述已执行脚本。
- 两个调度周期由实际后台 worker 在未来时刻触发，不能用改库时间或 fake clock 代替。120 次只读采样记录队列与预算；最终收尾再独立核对持久状态。

保留全部失败轮次：早期模型曾给错日期/引用区间、只用文字代替 SLA 执行，或耗尽单项预算；操作者也遇到材料重名 409、重建期间连接中断、验收时间格式 400、隧道失效以及验收脚本误读取消响应。真实模型修复后使用新证据目录重新验收，运维重试另存日志，没有以最终成功覆盖原始失败。单项模型预算最终显式设为 225000，授权总预算仍独立限制；用量未知时完整预留不退。

生产观察覆盖单个合成员工及有限实际周期，不证明多员工负载吞吐或长期公平性。多员工配额、公平性和安静时段另由可控双后端测试验证。

### 浏览器实际操作

CUA 连接正式 HTTPS 后端，使用仅回环的固定合成员工 Cookie 代理。桌面及 390 像素窄屏实际操作确认、暂停、恢复和取消；键盘 Enter 确认安排。未点确认前定义为 0，点确认后为 1。页面只保留一个执行安排工作窗口。

另一项真实模型生成的会议任务跨版本重建后保留候选。浏览器编辑标题，选择第一条待办和第二条日程，保留第三条不创建；实际只生成**1 待办、1 日程、1 站内提醒**。把同一原生请求再次提交，记录数量、任务版本和执行次数不变，派发索引立即 settled。最终清晰截图及精确请求的原始证据单独保存。

页面显示“飞书”来自合成身份，不是实际企业 OAuth 验收。真实飞书登录及真实外部消息发送均为 not_checked；本次不发送真实邮件、聊天消息或财务请求。

## 实际故障、恢复与额外一致性修复

| 层次 | 实际结果 |

| 副作用回执丢失 | 两环境真实持久 SQLite 下游写入后丢弃响应；实际写入计数均 1，任务 outcome_unknown，重复决定不重发 |

| 独立执行 daemon 重启 | PID 实际改变，两个平台容器和 boot_id 不变；两环境真实隔离探针通过，随后新真实模型工单任务通过 |

生产监控发现原生取消后任务已终态、派发索引仍停在 waiting_user。虽然不会再次认领，监控会失真。本轮补丁使任务终态与无资源待清理的派发状态同事务结清；有 lease 的资源仍由原 owner/epoch 释放。启动扫描修复历史残留，不重跑模型或补发通知。先得到 16 项失败，再 16 项通过；预发布实际修复 2 条旧索引，90 个对象与 28 条通知保持不变，仅新增一条正常主动扫描审计。

## 正式开放、隔离与收尾

正式 acme 租户先只开放持久交办，再开放触发及工作动态。最终三开关的 tenant_ids 均只含 acme，合成 HTTP 免状态工具名单为空；office-assistant 为 1.0.6，support-desk 保持原版。正式执行定义数量仍为 0，员工需明确确认新安排，旧 R1 终态和旧提醒没有自动转换为执行工作。

平台 UID10001、独立 executor UID10002、Unix socket 目录、idmapped 共享和既有资源限制保持不变。执行服务上限 6 GiB / 2 CPU / 4096 tasks，单项隔离探针实际验证 512 MiB / 1 CPU / 256 pids、仅 loopback、输入只读、宿主配置/对象和 Docker socket 不可见；成果导出 SHA 一致。既有 PostgreSQL 容器及镜像没有升级或重启。

两环境合成定义和未来触发已取消，提醒取消、待办/日程软回收、三名合成员工 Cookie 注销、临时 key 吊销、两名普通用户停用；保留末位管理员并暂停整个合成租户。保留 outcome_unknown 及所有效应/预算证据，不伪装成失败后重发。临时计数侧车、浏览器代理、SSH 隧道和预发布运行服务在核验后停止，数据库及证据归档保留。精确清理计数、最终源码核对和资源计数见脱敏 JSON。
