# 文档总入口

| 目录 | 是什么 | 给谁看 |
| --- | --- | --- |
| [guides/](guides/README.md) | 使用手册：快速上手、编写业务包、应用接入、部署与运维、审计与用量 | 使用平台的人 |
| [architecture/](architecture/README.md) | 当前生效的设计与参考资料（活文档，永远代表现状）：架构总览、业务包规范、HTTP 接口、内核缺口清单 | 使用平台的人查字段与接口；开发平台的人 |
| [decisions/](decisions/README.md) | ADR 决策记录（为什么这么定，只增不改） | 开发平台的人 |

各个包自己的说明在 `packages/<包名>/README.md`；可以直接运行的样例在 [`examples/`](../examples/)。
