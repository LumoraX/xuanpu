# 到人交接与组织审批候选

当前实现为未部署的 R3-D / E0 候选；与生产 R3-A、真实员工试点、真实模型验收分别记录。部门不是前置条件，真实试点使用陈翔和 drYang；没有根据企微可见范围或管理员身份授予业务权限。

只有启用的来源事项允许新交接。终态审批也按当前成果来源决定理由可读性，并纳入通知权限摘要；撤销独立阅读授权后已打开页面清除原理由。交接终态保留，不能因历史资料失效显示成新的待办。

交接由共享事项当前负责人原生确认。target_kind=user 时绑定明确启用员工及身份代次，只有本人可接收；unit 是可选当前任职与 unit_operator 资格路径。接收只产生该交接固定正文副本/精确材料版本的 packet，不提升完整事项 editor。并发认领使用租户及排序员工锁、交接 CAS；责任、事件、用途授权、回执与站内通知同一次协调事务提交。

统一共享读取入口检查用途的当前来源、冻结身份、原承办职责足迹和固定材料。原授权重新授予不恢复旧上下文。锁集合只追实际用途和材料 source_refs，不沿员工之间无关交接递归；新增独立 full 也不撤销仍有效的原 packet 依赖。

状态依次可为 submitted、accepted、in_progress、needs_information、delivered、signed_off，另有 returned、cancelled、disputed。补充与转交重新明确来源和材料，新员工重新接收，原授权撤销、未决审批 superseded。取消同事务结束相关未决审批，不占用永久 pending 容量。已合法交付的固定成果不因承办人离职被删除；发起人仍可核对签收。争议保留旧交付，失去原承办人时可带明确新输入改派，重新接收和审批。

组织审批不是个人工具批准。企业级组织管理人或租户管理员预配一至三步策略，选择明确员工或唯一 unit_approver；普通员工/申请人/模型不能覆盖审批人。用户策略绑定身份代次，单位策略冻结解析员工及职责足迹。候选读取后锁内重新覆盖完整候选集合，不唯一或并发新增候选都冲突；申请人自批被拒绝。配置管理员无需伪造员工身份，员工业务操作仍必须本人身份。

新请求须匹配交接已明确确认的当前策略修订；策略变更后先由负责人重新确认交接输入。已有请求继续使用其冻结修订，不由新规则偷换审批人。每步只当前真人审批，决定、回执、权限与通知同提交。只当前步取得成果临时 packet；成果完整 source_refs 仍逐级核对当前审批人，不能读的成果不可批准，也不自动扩张原来源 ACL。决定理由可能含正文，只在当前可读完整固定成果时显示；历史参与身份不等于永久内容权限。审批列表整页在同一最终协调事务投影。

成果使用共享发布意图、容量预留、事务外对象复制及最终 CAS。承办人只能创建本交接的新成果，不能覆盖输入或借成果用途获得 editor；固定助手文本保留服务端消息来源。接收时的原 packet 不因新成果发布被改写，成果使用独立用途 grant。复制前后再次核对交接版本、身份、原来源和共享版本，失败副本保持不可见并进入既有清理流程。

交付固定 material_id/revision/sha256；有策略时检查匹配的 approved 请求、目标 digest、责任代次及策略修订。交付记录不可改写，签收另引用精确 delivery_version；争议和重办不沿用旧目标批准，R2 任务成功不自动驱动 signed_off。

0018/0019 是当前尚未发布的迁移候选：交接、不可改写历史/交付、策略修订、审批步骤/决定、用途关联和来源通知与组织/共享资料同库事务。两后端共用租户、引用、固定成果 SHA、顺序决定及历史不变量。候选默认 handoffs/approvals 关闭；关闭新提交保留既有合法收尾。

通知只存通用提示与来源编号，不复制私有标题、理由或正文，不发外部消息。独立 sequence 在租户锁内分配，标读有 CAS/原操作号，统一通知接口与 SSE 使用 collaboration_after_id。每帧外发前补读当前资格。权限摘要覆盖未接收工作、固定身份与当前来源健康度；网页在首个快照及后续摘要变化时先清理，再对当前记录作只读核验。统一通知入口计入协作未读。

失效与期限扫描复用现有组织治理周期，单轮最多100单、轮转活跃集合，也收尾终态交接下遗留 pending 请求。系统事件不冒充任何员工。截止期限的站内提醒按持久事件语义去重，重启/并发只提醒一次，不自动认领、批准、交付或签收。

原生“功能 → 工作交接与审批”、默认对话草稿、SDK/CLI 共用上述接口。模型只能起草 title/summary 或打开入口，明确目标、范围和所有业务动作由本人原生确认。断线重试保留原操作号，409重新核对，身份切换和迟到响应使用代际保护。部署、真实企微和真实员工生产闭环尚待 R3-E 分层验收。
